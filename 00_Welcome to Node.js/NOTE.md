# 🎬 Episode 00 — Welcome to Node.js

> **45 Days of Understanding Node.js — From Basics to Under the Hood**

This is the starting point of my **45-Day Node.js Deep Dive Challenge**.

I have already learned Node.js before, but this time my goal is different. I don't want to simply remember APIs or write code—I want to **understand how Node.js actually works behind the scenes**.

Before starting the technical journey, this episode introduced some important principles that can make the learning process much more effective.

---

## 🧠 Key Lessons from Episode 00

### 1. 🔍 Be Curious

Don't just accept something because it works.

Whenever you learn something, ask:

* **Why does it work this way?**
* **What is happening behind the scenes?**
* **What happens when I change this?**
* **What is Node.js doing internally?**
* **Can I reproduce or test this behavior myself?**

> **Curiosity turns information into understanding.**

Instead of only learning *what* Node.js does, I want to continuously ask **why and how it does it**.

---

### 2. ✍️ Make Handwritten Notes

Writing notes by hand helps me actively process what I'm learning instead of passively consuming information.

While learning, I will write down:

* Important concepts
* My own understanding
* Questions that come to mind
* Diagrams and flow
* Things I initially misunderstood
* Interesting observations

The goal isn't to write everything from the video.

The goal is to write **what I understand**.

> **Don't copy the teacher's notes. Build your own understanding.**

---

### 3. 💻 Practice Along With the Video

Watching a tutorial is not enough.

Whenever the instructor demonstrates something, I should try it myself.

```text
Watch → Understand → Code → Experiment → Break → Fix → Understand
```

I want to experiment with the code instead of simply copying it.

For example, if I learn something about the Node.js event loop, I shouldn't stop at understanding the explanation.

I should create different examples, change the code, observe the output, and ask:

> **"Why did this happen?"**

That's where deeper understanding begins.

---

### 4. 📅 Make a Learning Schedule

One of the best ways to learn consistently is to have a **clear schedule**.

For this challenge, I am following a **45-day learning journey**.

A schedule helps me:

* Stay consistent
* Track my progress
* Avoid random learning
* Build a daily habit
* Know what I need to study
* Complete the challenge systematically

> **Consistency is more important than studying a huge amount in one day.**

The goal is not to rush through Node.js.

The goal is to **understand Node.js deeply, one concept at a time.**

---

### 5. 🌍 Join an Open Community

Learning doesn't have to happen alone.

Joining communities such as **Discord developer communities** can help with:

* Asking questions
* Discussing concepts
* Getting different perspectives
* Sharing problems
* Learning from experienced developers
* Helping other learners

But there is something even more important:

> **When you help someone else understand a concept, you often understand it better yourself.**

If I can explain a concept clearly to another person, it is a strong sign that I actually understand it.

So I want to follow this cycle:

```text
Learn → Practice → Discuss → Help Others → Understand Better
```
